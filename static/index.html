A little science. A little estimation.

Hardware detection runs locally on page load. It uses browser-reported OS, approximate RAM and GPU identity where available. A matched M2 Pro or base M5 uses nominal chip bandwidth. On identified Apple M chips, rounded system RAM can seed an editable planning budget. Desktop RTX 4090 and explicitly identified RTX 3060 12 GB presets use estimated budgets. Enter missing values from your own device. Hardware details are not sent to Hugging Face.

Search queries the public Hugging Face Hub API for text-generation models. Selecting a search result retrieves its model configuration and parameter metadata. Starter cards are a curated offline collection.

Weight memory ≈ parameters × bits ÷ 8, plus quantization overhead, an architecture-based KV cache and runtime headroom. Decode speed uses 45% of memory bandwidth and a 4 ms per-token runtime allowance, with an illustrative range of ±30%. This is a planning heuristic, not a calibrated benchmark interval. CPU offloading is not simulated: models that exceed available memory receive no speed prediction.

30 output tokens/sec is our adjustable default for comfortable chat. Dense models receive a speed heuristic. Mixture-of-experts models receive a rough full-weight memory requirement when the total parameter count is known, but no speed or bandwidth target. Their architecture-specific context cache is not calculated; expert offloading is not simulated. Unknown parameter counts are flagged.
